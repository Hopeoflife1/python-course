📢 The print() Function

print() tells the computer to display something on screen. Text (words) must go inside quotes. Numbers go without quotes. Everything you want shown goes inside the brackets ().

Python — your_first_program.py
# This is your very first Python program!
print("Hello, World!")
print("My name is Emeka")
print("I am from Lagos, Nigeria 🇳🇬")

# Numbers — no quotes needed
print(100)
print(3.14)

# Python can do maths inside print()
print(10 + 5)     # 15
print(100 - 30)   # 70
print(4 * 3)      # 12
print(20 / 4)     # 5.0

# Print multiple items using commas
print("I am", 15, "years old")    # I am 15 years old

# Repeat text using *
print("=" * 30)      # prints 30 equal signs
print("Na!" * 5)     # Na!Na!Na!Na!Na!

sep= and end= — Control your output:

Python — sep and end parameters
# sep= changes what goes BETWEEN items (default is a space)
print("Lagos", "Abuja", "Kano", sep=", ")    # Lagos, Abuja, Kano
print("2024", "05", "19", sep="-")          # 2024-05-19
print(1, 2, 3, 4, 5, sep=" | ")             # 1 | 2 | 3 | 4 | 5

# end= changes what appears at the END (default is a new line)
print("Hello", end=" ")    # no new line — continues on same line
print("World!")             # Hello World!  (on ONE line)

print("Loading", end="...")
print("Done!")               # Loading...Done!

Escape Sequences — Special characters inside strings:

Python — escape sequences
print("Name:\tEmeka")          # \t = TAB (big space)
print("City:\tLagos")
print("Line1\nLine2\nLine3")  # \n = NEW LINE
print('It\'s a great day!')    # \' = apostrophe inside single quotes
print("She said \"Hello!\"")    # \" = quote inside double quotes
print("C:\\Users\\Emeka")       # \\ = actual backslash character

Comments — Notes that Python ignores:

Python — comments
# This is a single-line comment. Python ignores this completely.
print("Hello")   # You can also comment at the end of a code line

"""
This is a multi-line comment (also called a docstring).
Write as many lines as you want here.
Python ignores ALL of this text.
Use it for long explanations.
"""
print("Done!")
💡 Always comment your code! Months from now, you will forget what you wrote. Good comments make you a professional programmer — and make your teacher very happy.

📦 What is a Variable?

A variable is a labelled storage container. You give it a name, put data inside, and use it anywhere in your program. To create one: name = value

🇳🇬 Analogy: A variable is like a labelled konga bag. The bag is called "my_money". Today you put ₦5,000 inside. Tomorrow you add ₦2,000. Next week you spend ₦3,000. The bag always holds the current value — and you can check or change it anytime.
⚠️ The = sign in Python does NOT mean "equals"! It means "put this value INTO this variable." It's called the assignment operator. To CHECK if two things are equal, you use == (double equals). This difference causes many beginner bugs!
Python — creating and using variables

🔍 Indexing — One Character at a Time

Every character has a position number called an index. First character is index 0. Python also counts from the END using negative numbers.

Python — string indexing
word = "NIGERIA"
#       N  I  G  E  R  I  A
# Pos:  0  1  2  3  4  5  6
# Neg: -7 -6 -5 -4 -3 -2 -1

print(word[0])     # N  — first character
print(word[3])     # E
print(word[6])     # A  — last character
print(word[-1])    # A  — last (from end)
print(word[-3])    # R  — third from end
✂️ Slicing — Multiple Characters

Syntax: string[start : end : step] — the end index is NOT included!

Python — string slicing
s = "ABCDEFGHIJ"

print(s[0:4])      # ABCD  — index 0,1,2,3 (stops BEFORE 4)
print(s[3:7])      # DEFG
print(s[5:])       # FGHIJ — from 5 to end
print(s[:4])       # ABCD  — from start to 3
print(s[:])        # ABCDEFGHIJ — whole string
print(s[::2])      # ACEGI — every 2nd character
print(s[::-1])     # JIHGFEDCBA — REVERSED! (step of -1)

# Real example: extract parts of a date
date  = "2024-05-19"
year  = date[:4]    # "2024"
month = date[5:7]   # "05"
day   = date[8:]    # "19"
print(year, month, day)
💡 Reverse any string: text[::-1] — the -1 step means "go backwards". This is one of Python's most famous tricks!
✨ F-Strings — The Professional Way

F-strings let you embed variables directly inside text. Put f before the opening quote, then put variables in {curly braces}. This is the modern, recommended approach — use it always!

Python — f-strings (use these always!)
name  = "Bisi"
age   = 16
score = 87.5
price = 1234567.89

# Basic f-string
print(f"My name is {name} and I am {age} years old")

# Expressions inside {}
print(f"Next year I will be {age + 1}")
print(f"Name has {len(name)} letters")
print(f"Uppercase: {name.upper()}")

# Number formatting
print(f"Score: {score:.2f}%")         # 87.50% — 2 decimal places
print(f"Price: ₦{price:,.2f}")        # ₦1,234,567.89 — commas + 2dp
print(f"Score: {score:.0f}%")         # 88% — rounded, no decimals

# Text alignment inside f-strings
print(f"{'NIGERIA':^30}")              # centered in 30 characters
print(f"{'Lagos':<30}")                # left-aligned in 30 characters
print(f"{'Abuja':>30}")                # right-aligned in 30 characters
print(f"{'Kano':*^30}")               # centered, filled with *

🔄 The While Loop
🇳🇬 Analogy: A while loop is like a fuel station attendant: WHILE the tank is not full, keep pumping fuel. The moment the tank is full, STOP. Python keeps running the loop body as long as the condition stays True — checking it before every single repetition.

🌍 Local vs Global Scope
🇳🇬 Analogy: Scope is like floors in a building. A variable on the ground floor (global) can be seen from everywhere. A variable in a specific room (local) can only be seen inside that room. When you leave the room (function ends), the local variable disappears.
Python — scope rules
# GLOBAL variable — defined outside functions
country = "Nigeria"   # global — visible everywhere

def show_country():
    print(country)   # can READ global variable

show_country()       # Nigeria

# LOCAL variable — defined inside function, invisible outside
def my_func():
    local_var = "I only exist inside!"
    print(local_var)

my_func()
# print(local_var)  # NameError! local_var doesn't exist here

# global keyword — MODIFY a global variable inside a function
score = 0

def add_point():
    global score        # tell Python: use the global 'score'
    score += 10

add_point()
add_point()
add_point()
print(score)         # 30

# LEGB RULE — Python searches in this order:
# L = Local (inside current function)
# E = Enclosing (outer function if nested)
# G = Global (module level)
# B = Built-in (print, len, etc.)

x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)    # local — closest scope wins
    inner()
    print(x)        # enclosing

outer()
print(x)            # global

# nonlocal — modify ENCLOSING variable from inner function
def make_counter():
    count = 0
    def increment():
        nonlocal count   # use the enclosing 'count'
        count += 1
        return count
    return increment

click = make_counter()
print(click())   # 1
print(click())   # 2
print(click())   # 3
💡 Best Practice: Avoid using global variables. Instead, pass data as function parameters and return results. This makes functions clean, testable, and reusable.

# A decorator wraps another function
from functools import wraps
import time

def timer(func):
    @wraps(func)   # preserves __name__ and __doc__
    def wrapper(*args, **kwargs):
        start  = time.time()
        result = func(*args, **kwargs)
        end    = time.time()
        print(f"{func.__name__}() took {(end-start)*1000:.2f}ms")
        return result
    return wrapper

def logger(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}() with args={args}")
        result = func(*args, **kwargs)
        print(f"{func.__name__}() returned {result}")
        return result
    return wrapper

# Apply with @ syntax -- stack multiple decorators!

@logger

    return a + b

@timer

    return sum(range(n))
